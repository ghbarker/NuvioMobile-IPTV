## Live TV
- Smarter live buffer for IPTV channels (slows down a little when the buffer runs low)
- Large Stalker portals that were too big to load in one go now load page by page
- Download playlist movies and episodes to a folder you pick (Downloads shows them for offline viewing)
- On Demand: optional switch to clean movie and series group names with the same cleanup words as channels
- Setup Sync: a new phone gets seek preview choices (on/off, when, storage limit) and more app choices; Include 4K, buffer sizes and brightness stay on each phone

## Recordings
- Finished series recordings are grouped into show folders
- Rename a finished recording
- Recordings keep the episode's guide description
- Streams that redirect or have no file ending now record properly
- Save a network folder recording on the phone to watch offline (hold a recording → Save for offline); works when the folder can't be reached
